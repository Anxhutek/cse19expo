## 📁 Repository Overview & Project Directory

This repository is divided into specific experiments and tasks covering Frontend (HTML, CSS, React.js) and Backend (Java, Spring Boot REST APIs).

### 🌐 1. HTML & CSS Basics (Static Web Pages)
Simple and semantic web pages implementing CSS styling, layout models, and responsiveness:
* **exp1.html:** Basic structure, forms, and layout techniques.
* **exp2.html:** Advanced CSS positioning, flexbox/grid layouts, and responsive elements.
* **exp3.html:** Styling forms, menus, and media integration.
* **pattern.html / sample.html / task.html:** CSS design tasks, pattern implementations, and layouts.

### ⚛️ 2. React.js Applications (Vite Ecosystem)
Single Page Applications (SPAs) built using **React.js** and **Vite**:
* **ex7/**: React app with component composition, state hooks (`useState`), and dynamic UI components.
* **exp8/**: Vite + React application focusing on form validation, event handling, and controlled components.
* **exp9/**: Modern UI layout exploring state management, components, and props.
* **st1/**: React assignment exploring styled custom interfaces.
* **exp4 / exp5 / exp6**: Lightweight React exercises demonstrating hooks, event listeners, and styling.

### ☕ 3. Java & Spring Boot REST APIs (Backend)
Backend developments focusing on RESTful services and Java Object-Oriented concepts:
* **exp10.java**: Object-oriented Java application showcasing core Java features.
* **exp11/ (Student API)**: A Spring Boot REST API for managing student records. Performs CRUD operations and integrates with a database.
* **exp12/ (Employee API)**: A Spring Boot application showcasing Repository pattern, Service layer, and Controller-based REST endpoints for employee management.
